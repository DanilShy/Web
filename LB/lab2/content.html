CSS: Шрифти, текст, таблиці, фон, контур, списки, CSS просунуті

CSS (Cascading Style Sheets) — це мова стилів, яка використовується для оформлення веб-сторінок. CSS дозволяє змінювати шрифти, кольори, відступи, розміри та багато інших властивостей елементів HTML.

Шрифти: CSS дозволяє використовувати різні шрифти за допомогою властивості font-family. Наприклад, можна використовувати системні шрифти або підключати шрифти з Google Fonts.

Текст: За допомогою CSS можна змінювати стиль тексту, включаючи його розмір (властивість font-size), колір (властивість color), та вирівнювання (властивість text-align).

Таблиці: CSS дозволяє стилізувати таблиці, змінюючи такі властивості, як межі, відступи та фон. Властивості border, padding та background-color є корисними для оформлення таблиць.

Фон: CSS дозволяє налаштовувати фон елементів, використовуючи властивість background, яка може приймати кольори, градієнти та зображення.

Контур: Властивість outline дозволяє створювати контури навколо елементів, які не займають місця в макеті.

Списки: CSS дозволяє стилізувати списки, наприклад, змінюючи маркери, відступи та шрифт за допомогою властивостей list-style-type і padding.

Просунуті властивості CSS: Включають трансформації, анімації та медіа-запити, які дозволяють адаптувати стилі для різних екранів і пристроїв.

Висновки до ЛР №2

У результаті виконання лабораторної роботи №2 ми ознайомилися з основами CSS та різними способами його підключення. Ми дізналися, як CSS впливає на стиль та оформлення веб-сторінок, включаючи шрифти, кольори, фони та контури елементів. Також ми розглянули важливість селекторів у CSS, які дозволяють вибирати елементи для стилізації, та їх різновиди, такі як селектори тегів, класів та ідентифікаторів.

Використання CSS відкриває широкі можливості для дизайну веб-сторінок, дозволяючи створювати привабливі та функціональні інтерфейси. Знання основ CSS є важливим для веб-розробників, оскільки це дозволяє створювати якісні та адаптивні сайти, що відповідають сучасним вимогам користувачів.
